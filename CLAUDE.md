# Working with Claude here

## Brainstorming (product ideas, UI, features)

- Start short and simple. Expand only when asked.
- Layouts as text (ASCII wireframes), not HTML pages or artifacts.
- Features as brief bullets. No code until the design is agreed.
- Desktop first unless told otherwise.
- Flow: text layout → features → review (a second model may critique) → smallest v1 → build.
